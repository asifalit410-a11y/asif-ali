Asif Ali Portfolio - GitHub Pages guide
=======================================
Files: index.html + images/ folder + videos/ folder.
Keep them together exactly like this (all links are relative).

Publish on GitHub Pages:
1) Create a new GitHub repository (public).
2) Upload the CONTENTS of this folder (index.html, images, videos) to the repository root.
3) Repository Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4) After a minute your site is live at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Contact form email (optional):
 Get a free key at web3forms.com, open index.html and paste it in CONFIG -> web3formsKey.

Edit content: the CONFIG block near the bottom of index.html (links, stats, skills, projects, gallery).
